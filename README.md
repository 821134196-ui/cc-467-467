# 物业备用发电机试运行与燃油补给平台

管理楼宇备用发电机组的额定功率、启动电池、燃油液位、试运行计划、带载步骤、
运行参数、故障停机、加油记录与维修封锁。设备与读数全部为模拟数据，
零第三方依赖（仅 Python 标准库 + 原生前端）。

## 一条命令启动（创建正常 / 启动失败 / 漏油样例）

```bash
python -m genplat demo            # 初始化 data/genplat.db（幂等）并启动
python -m genplat demo --reset    # 清空重建样例
```

打开 http://127.0.0.1:8000/ 。环境变量：`GENPLAT_HOST` / `GENPLAT_PORT` /
`GENPLAT_DB` / `GENPLAT_ATTACH`。

其他命令：

```bash
python -m genplat serve       # 使用既有数据库启动（不重建）
python -m genplat testdata    # 仅建样例数据
python -m unittest discover   # 23 项领域规则测试
python tests/e2e_http.py      # HTTP 端到端冒烟（先启动服务）
```

## 业务规则

- **计划审批门控**：计划经工程主管批准后才能执行试运行；取消单独留痕。
- **会话互斥**：同一计划 / 同一机组同时只保留一个运行会话（SQLite 部分唯一索引
  在数据库层兜底，两个值班员同时点“开始”只成功一个）。
- **步骤顺序**：外观 → 油位 → 启动电池 → 空载启动 → 带载测试，须依次合格；
  **越过检查步骤必须由工程主管批准**，且只能越过当前最早待执行步骤。
- **维修封锁**：封锁机组不能启动（阻断事件留痕），不计入应急可用容量；
  参数带与状态徽章始终带锁形图标和文字说明；仅主管可挂牌/摘牌。
- **结束核算**：记录运行时长，按液位差折算实耗，与按时长/负载推算的账面耗油
  比较，差异超 5L 记“燃油差异”事件；全部合格后机组回到待命。
- **故障停机**：启动失败（E101）、电压越限（E202）、异常噪声（E404）、
  漏油（E505）、带载中断（E303）均故障停机并全程留痕；启动前检查不通过则
  中止会话、机组保持待命。
- **加油台账**：加油员/主管登记；**数量修订生成待复核记录，第二人复核后才改动
  液位，提交人不能自审**；复核通过冲销旧记录并按新数量重算液位。

## 七个视图

机组总览（单行参数带，非拟真仪表盘）· 试运行日历（月历 + 计划列表）·
步骤执行（纵向时间线，实时数值与合格区间并排）· 参数趋势（电压/频率/液位
三个独立单轴 SVG 小图，越限点红点、漏油三角，带十字线与表格视图）·
故障停机（异常会话 + 留痕事件流）· 燃油台账（登记/修订/复核/平衡）·
审批记录（计划批准、越步批准、加油复核待办与留痕）。

右上角可切换演示身份：值班员（执行）、工程主管（审批/封锁）、加油员（加油）。

## 架构

```
genplat/
  config.py     步骤定义、合格区间、角色、状态、事件类型、配色
  db.py         SQLite schema / 连接 / 只追加事件流 / 互斥部分唯一索引
  service.py    领域服务：审批、互斥、步骤顺序、封锁、燃油平衡、复核、留痕
  simulator.py  后台线程：normal/start_fail/leak 三工况持续生成读数；
                到期计划 / 低油位提醒（alerts + 事件留痕）
  seed.py       5 台机组（含封锁、低油位）与正常/启动失败/漏油三条计划
  app.py        http.server JSON API + 静态页面（X-User-Id 演示身份）
  static/       index.html / styles.css / app.js（零构建原生前端）
tests/
  test_service.py  单元测试（互斥/顺序/越步/封锁/燃油/复核/故障/模拟器/提醒）
  e2e_http.py      HTTP 端到端链路
```

SQLite 保存全部运行事件（`events` 只追加），现场附件（漏油照片、异常录音等）
存放于本地 `attachments/unit_<id>/`。
