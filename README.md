# 备用发电机试运行与燃油补给平台（genops）

面向物业的备用发电机运维平台：管理楼宇机组、试运行计划审批、五步带载试运行、
运行参数监测、故障停机留痕、加油台账与维修封锁。设备与读数均为**模拟数据**，
零第三方依赖（Python 3.10+ 标准库）。

## 一条命令启动

```bash
./run.sh                 # 或：python3 -m genops.cli demo
# 指定端口：./run.sh 8123
```

启动后自动打开浏览器 <http://127.0.0.1:8000>。数据存放于 `./data/`
（SQLite `genops.db` + `attachments/` 现场附件目录），可用 `GENOPS_HOME` 覆盖。

其他命令：

```bash
python3 -m genops.cli serve            # 不重置数据，直接启动
python3 -m genops.cli seed --reset     # 仅重置并播种
python3 -m genops.cli reset            # 删除本地数据库
```

## 业务规则

- **计划先批后做**：仅 `approved` 计划可启动；批准/驳回仅工程主管；取消必填原因并留痕。
- **会话互斥**：两个值班员同时（或先后）开始同一计划，只保留**一个运行会话**，后到者复用。
- **五步顺序**：外观 → 油位 → 启动电池 → 空载启动 → 带载测试，不得跳步；
  越过任一步骤必须工程主管批准，写入审批记录。
- **结束结算**：记录运行时长与实测剩余燃油，按“空载/带载分钟 × 单耗”推算理论消耗，
  差额超 5L 自动产生燃油差异事件；全部合格机组才回到**待命**。
- **维修封锁**：封锁机组禁止启动并从应急可用容量剔除；封锁会立即中止进行中的会话；
  解封仅工程主管。
- **加油双岗**：加油先登记（不动账面），必须由**第二人**（不得是登记本人）复核；
  修订数量由复核人确认后入账，超容量自动截断并告警。
- **留痕事件**：启动失败、电压/频率越限、异常噪声、漏油、带载中断、燃油差异、
  计划取消、封锁/解封、越步批准全部落 SQLite `events` 表。

合格区间：电压 380–420 V、频率 49.5–50.5 Hz、电池 24–28 V、试运行油位 ≥25%、
低油位告警 <20%（均在 `genops/config.py`）。

## 页面

机组总览（单行参数带，非拟真仪表盘）· 试运行日历（月历 + 计划审批/取消）·
步骤执行（纵向展开，实时值与合格区间并排）· 参数趋势（内联 SVG，电压/频率/液位/电池）·
故障停机（分类筛选 + 现场附件）· 燃油台账（加油登记/复核/流水勾稽）· 审批记录。
维修封锁在所有页面均带 🔒 图标与文字说明。配色：设备灰 / 柴油黄 / 运行绿。

## 模拟适配器与提醒

- 后台线程每 2 秒采样电压、频率、电池、液位；运行中按单耗消耗燃油，
  越限 15 秒去重报警，`normal/start_fail/oil_leak` 三种模式与临时波形注入
  （趋势页“模拟电压骤降/骤升/频率越限”按钮，或 `POST /api/sim/inject`）。
- 进程内任务每 10 秒扫描：30 分钟内到期的已获批计划、低油位机组，去重后提醒。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：并发会话互斥、步骤顺序与越步审批、封锁阻断/容量剔除/中止会话、
燃油台账平衡与第二人复核（含修订、驳回、超容截断）、计划审批权限、
启动失败/漏油/噪声/带载中断/越限停机、到期与低油位提醒去重（共 29 例）。
